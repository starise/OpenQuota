# OpenQuota

OpenQuota tracks provider allowances and usage for AI coding tools.

## Language

**Quota**:
A provider's usage allowance for an account over a given period.

**Estimated spend**:
The dollar value calculated by applying model prices to recorded usage.

**Token usage**:
The total number of tokens in the recorded usage for an account and period.

**Partial spend**:
The known cost for a period that also contains recorded usage without a cost.

**Last known rate**:
The most recent price OpenQuota observed for an exact model identifier that is absent from the
current catalogs.
